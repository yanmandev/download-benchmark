# download-benchmark

Консольный скрипт, который измеряет скорость скачивания по указанному адресу.
Делает N последовательных запросов, каждый раз дожидаясь полного ответа,
и выводит среднее время запроса, общий объём скачанных данных и скорость.

Зависимостей нет, нужен Node.js 18.3+ (используются встроенные `fetch` и `util.parseArgs`).

## Запуск

```bash
node index.js <url> [-n <count>]
```

| Аргумент            | Описание                                        |
| ------------------- | ----------------------------------------------- |
| `<url>`             | адрес для скачивания, только `http` / `https`, файл до 1 GB |
| `-n`, `--count`     | количество запросов, целое от 1 до 10000 (по умолчанию 10) |
| `-h`, `--help`      | справка                                         |

Примеры:

```bash
node index.js https://proof.ovh.net/files/10Mb.dat
node index.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg -n 5
npm start -- https://example.com/image.jpg --count 3
```

Если в адресе есть `&`, `?` или другие спецсимволы, оберните его в кавычки,
иначе оболочка (PowerShell, bash) разберёт их сама и до скрипта адрес не дойдёт:

```powershell
node index.js "https://example.com/image?id=1&n=13" -n 5
```

## Единицы измерения

| Величина             | Единица   | Пояснение                                  |
| -------------------- | --------- | ------------------------------------------ |
| Время запроса        | мс        | от отправки запроса до получения последнего байта тела |
| Объём данных         | MB        | мегабайты, 1 MB = 1 000 000 байт           |
| Скорость скачивания  | Mbit/s    | мегабиты в секунду, 1 Mbit = 1 000 000 бит |

Скорость в Mbit/s выбрана потому, что в ней обычно указывают скорость интернет-канала,
так что результат удобно сравнивать с тарифом провайдера.

Скорость считается как `общий объём / суммарное время всех запросов`,
среднее время — как `суммарное время / количество запросов`.
Объём — это размер тела ответа после распаковки: если сервер отдал данные
со сжатием (gzip, br), `fetch` их распакует, и учтётся распакованный размер.
Для картинок и бинарных файлов сжатие обычно не применяется, так что это не влияет на результат.

## Пример вывода

```
Downloading https://example.com/image.jpg 3 time(s)...

#1: 4.53 MB in 812 ms
#2: 4.53 MB in 640 ms
#3: 4.53 MB in 655 ms

Average request time: 702 ms
Total downloaded:     13.59 MB
Download speed:       51.61 Mbit/s
```

## Валидация

- адрес должен разбираться через `new URL()` и иметь протокол `http:` или `https:`;
- количество запросов — целое число от 1 до 10000;
- размер файла — не больше 1 GB (1 000 000 000 байт). Если сервер сразу прислал
  `Content-Length` больше лимита, скачивание не начинается. Если заголовка нет или он врёт,
  размер проверяется во время чтения, и скачивание прерывается, как только лимит превышен;
- если сервер ответил не 2xx или запрос упал по сети, скрипт завершается с кодом 1.
